# InvMenu 4.7.5 for RyzeMP

InvMenu now uses the published RyzeMP Composer API directly. The package name is
`ryzecompany/invmenu`, and it requires `ryzemcbe/ryzemp:^5.44.2-p1` automatically.
Existing PHP imports remain under `muqsit\invmenu`.

The release fixes per-player block palettes, restoration through RyzeMP's World
API, legacy close packets, hopper retry types and stalled/reentrant menu opening.

Validation includes 16 regression scenarios on PHP 8.1, 8.3 and 8.4 with both World
API signatures, a clean Composer consumer using real RyzeMP protocol data and
inventory classes, and protocol 2225 in the palette regression.

In a Composer project, allow the tagged beta Bedrock dependencies while preferring
stable releases, then require the library:

```bash
composer config minimum-stability beta
composer config prefer-stable true
composer require ryzecompany/invmenu:^4.7.5
```

The version is available through Packagist after the repository has been registered
and indexed. Rebuild plugin PHARs that bundle InvMenu using this fork. The library
is a plugin dependency/virion, rather than a standalone server plugin.
